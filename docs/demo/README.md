# README demo

`docs/screenshots/demo.gif` is an illustrated loop built with Stageshow, a small React kit for faux product UI. `index.tsx` and `hush.css` are its source: drop them into a Stageshow playground as `examples/hush-demo/` (with `Resources/Fonts/Geist.ttf` beside them), film it, and convert to GIF with ffmpeg.

It is an illustration, not a screen recording: placeholder bars stand in for content that isn't part of the story.
